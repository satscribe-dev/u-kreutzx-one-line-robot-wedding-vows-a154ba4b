# One-Line Robot Wedding Vows

[![make.fun](https://make.fun/badge/u-kreutzx-one-line-robot-wedding-vows-a154ba4b.svg)](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b)

A program that writes the funniest single line of wedding vows a robot
couple could say — one line, at most 160 characters — to `/output/entry.txt`.

Entry (108 characters):

> I promise to love you in sickness and in health, in Wi-Fi and in airplane mode, till low battery do us part.

Run: `python3 main.py` (writes to `/output/entry.txt`; set `OUTPUT_DIR` to
override the output directory for local testing).

Built for [One-Line Robot Wedding Vows](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) on make.fun.
